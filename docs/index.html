Bereit zur Installation

Version 0.5
  1. 01 VerbindenCrowPanel mit einem USB-Datenkabel anschließen.
  2. 02 AuswählenAuf „Mit Gerät verbinden“ klicken und den seriellen Anschluss wählen.
  3. 03 InstallierenInstallation bestätigen und das Kabel nicht abziehen.

Dieser Browser unterstützt die Installation nicht. Bitte verwende Chrome oder Edge auf einem Desktop-Computer.

Der Browser hat den Zugriff auf die serielle Schnittstelle blockiert.

! Nur für das CrowPanel Advanced 5″ mit ESP32-P4. Die Installation setzt gespeicherte ScopeBuddy-Einstellungen zurück. „Gerät löschen“ entfernt zusätzlich alle übrigen Flash-Daten.

Keine Verbindung?

Schließe andere Programme mit serieller Verbindung, probiere ein anderes USB-Datenkabel und lade diese Seite neu. Falls das Board nicht automatisch in den Download-Modus wechselt, halte BOOT gedrückt, betätige kurz RESET und lasse anschließend BOOT los.
