Kompatibilität

Nur für das Elecrow CrowPanel Advanced 5″

Dieser Installer ist ausschließlich für das Elecrow CrowPanel Advanced 5″ mit ESP32-P4 und 800 × 480 Pixeln vorgesehen. Verwende ihn nicht mit einem anderen ESP32 oder Display.

Firmware 0.5.1

Browser-Installation

ScopeBuddy installieren

Diese Webseite überträgt ScopeBuddy 0.5.1 direkt über USB auf das Display. Dafür sind weder ESP-IDF noch Python oder Git notwendig.

!

Nutzung auf eigene Gefahr. ScopeBuddy befindet sich noch in Entwicklung und ist keine fertig entwickelte oder abschließend getestete Software. Bei der Installation werden vorhandene Flash-Daten gelöscht.

Schritt für Schritt

So funktioniert die Installation

Führe die folgenden Schritte in genau dieser Reihenfolge aus.

  1. 01
    Display per USB verbinden

    Das Elecrow-Display mit einem USB-Datenkabel an den Rechner anschließen.

  2. 02
    Download-Modus aktivieren

    Auf der Rückseite des Displays BOOT gedrückt halten, RST kurz drücken und anschließend BOOT loslassen.

    BOOThalten → RSTdrücken → BOOTloslassen
  3. 03
    Verbindung starten

    Auf dieser Seite auf „Mit Gerät verbinden“ klicken.

  4. 04
    Seriellen Port auswählen

    Im Browserdialog „ESP32-P4“ als seriellen Port auswählen und die Verbindung bestätigen.

  5. 05
    ScopeBuddy auswählen

    Im Installer auf „Install ScopeBuddy“ klicken.

  6. 06
    Löschen erlauben

    Die Option „Erase Device“ erlauben. Dabei werden die bisherigen Flash-Daten des Geräts gelöscht.

  7. 07
    Installation bestätigen

    Die Sicherheitsabfrage bestätigen, um das Übertragen der Firmware zu starten.

  8. 08
    Installation abwarten

    Das USB-Kabel nicht trennen und warten, bis der Installer „Wrapping up“ anzeigt.

  9. 09
    Display neu starten

    Wenn „Wrapping up“ erscheint, einmal kurz die RST-Taste auf der Rückseite des Displays drücken.

  10. 10
    Fertig

    ScopeBuddy startet nun automatisch auf dem Display.

Display angeschlossen und Download-Modus aktiviert?

Dieser Browser unterstützt die Installation nicht. Bitte verwende Chrome oder Edge auf einem Desktop-Computer.

Verbindungsprobleme

Keine Verbindung?

Prüfe zuerst, ob ein USB-Datenkabel verwendet wird und keine andere Anwendung den seriellen Port geöffnet hat. Lade danach die Seite neu und wiederhole die vollständige Tastenfolge auf der Rückseite: BOOT gedrückt halten, RST kurz drücken und erst danach BOOT loslassen. Klicke anschließend erneut auf „Mit Gerät verbinden“ und wähle „ESP32-P4“ aus.
