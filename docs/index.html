Bereit zur Installation

Version 0.5

Vor dem Verbinden erforderlich

CrowPanel in den Download-Modus versetzen

Ohne diese Tastenkombination wird der ESP32-P4 nicht im Browser angezeigt.

BOOThalten → RSTkurz drücken → BOOTloslassen
  1. 01 USB verbindenCrowPanel mit einem USB-Datenkabel anschließen.
  2. 02 Download-ModusBOOT halten, kurz RST drücken und danach BOOT loslassen.
  3. 03 Gerät auswählenAuf „Mit Gerät verbinden“ klicken und den seriellen Anschluss wählen.
  4. 04 InstallierenInstallation bestätigen und das Kabel nicht abziehen.
  5. 05 ScopeBuddy startenBei „Wrapping up“ einmal kurz die RST-Taste drücken.

Dieser Browser unterstützt die Installation nicht. Bitte verwende Chrome oder Edge auf einem Desktop-Computer.

Der Browser hat den Zugriff auf die serielle Schnittstelle blockiert.

RST Manueller Neustart des CrowPanels Sobald der Installer „Wrapping up“ anzeigt, ist die Firmware übertragen. Drücke dann einmal kurz RST, damit ScopeBuddy startet.

! Nur für das CrowPanel Advanced 5″ mit ESP32-P4. Die Installation setzt gespeicherte ScopeBuddy-Einstellungen zurück. „Gerät löschen“ entfernt zusätzlich alle übrigen Flash-Daten.

Keine Verbindung?

Schließe andere Programme mit serieller Verbindung, probiere ein anderes USB-Datenkabel und lade diese Seite neu. Wiederhole danach die vollständige Tastenfolge: BOOT gedrückt halten, RST kurz drücken und erst anschließend BOOT loslassen. Klicke danach erneut auf „Mit Gerät verbinden“.
