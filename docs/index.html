Kompatibilität

Nur für das Cheap Yellow Display 2432S028

Dieser Installer ist ausschließlich für das ESP32-2432S028 („Cheap Yellow Display“, 2,8″ mit 320 × 240 Pixeln, CH340C-USB-Brücke) vorgesehen. Verwende ihn nicht mit einem anderen ESP32 oder Display. Das Projekt ist ein Fork of ScopeBuddy.

Firmware 0.6.0

Browser-Installation

Aiuto-Vista installieren

Diese Webseite überträgt Aiuto-Vista 0.6.0 direkt über USB auf das Display. Dafür sind weder ESP-IDF noch Python oder Git notwendig.

!

Nutzung auf eigene Gefahr. Aiuto-Vista befindet sich noch in Entwicklung und ist keine fertig entwickelte oder abschließend getestete Software. Bei der Installation werden vorhandene Flash-Daten gelöscht.

Schritt für Schritt

So funktioniert die Installation

Führe die folgenden Schritte in genau dieser Reihenfolge aus.

  1. 01
    Display per USB verbinden

    Das Display mit einem USB-Datenkabel an den Rechner anschließen (USB-Anschluss an der kurzen Seite, neben dem Audio-Klinkenstecker).

  2. 02
    Download-Modus aktivieren

    Auf der Platine BOOT gedrückt halten, RST kurz drücken und anschließend BOOT loslassen.

    BOOThalten → RSTdrücken → BOOTloslassen
  3. 03
    Verbindung starten

    Auf dieser Seite auf „Mit Gerät verbinden“ klicken.

  4. 04
    Seriellen Port auswählen

    Im Browserdialog den Port auswählen, der „CH340“ im Namen enthält, und die Verbindung bestätigen.

  5. 05
    Aiuto-Vista auswählen

    Im Installer auf „Install Aiuto-Vista“ klicken.

  6. 06
    Löschen erlauben

    Die Option „Erase Device“ erlauben. Dabei werden die bisherigen Flash-Daten des Geräts gelöscht.

  7. 07
    Installation bestätigen

    Die Sicherheitsabfrage bestätigen, um das Übertragen der Firmware zu starten.

  8. 08
    Installation abwarten

    Das USB-Kabel nicht trennen und warten, bis der Installer „Wrapping up“ anzeigt.

  9. 09
    Display neu starten

    Wenn „Wrapping up“ erscheint, einmal kurz die RST-Taste auf der Platine drücken.

  10. 10
    Fertig

    Aiuto-Vista startet nun automatisch auf dem Display.

Version 0.6.0 ist die aktuelle, empfohlene Version.

Display angeschlossen und Download-Modus aktiviert?

Dieser Browser unterstützt die Installation nicht. Bitte verwende Chrome oder Edge auf einem Desktop-Computer.

Verbindungsprobleme

Keine Verbindung?

Prüfe zuerst, ob ein USB-Datenkabel verwendet wird und keine andere Anwendung den seriellen Port geöffnet hat. Lade danach die Seite neu und wiederhole die vollständige Tastenfolge auf der Platine: BOOT gedrückt halten, RST kurz drücken und erst danach BOOT loslassen.

Installation per esptool (Fallback)

Browser-Installation funktioniert nicht?

Das 2432S028 nutzt die CH340C-USB-Brücke. Diese erscheint im Browserdialog zwar als serieller Port, die Web-Serial-Übertragung kann aber bei manchen CH340-Varianten fehlschlagen. Lade dann die Firmware-Datei aiuto-vista-v0.6.0.bin herunter (bei GitHub Pages bereitgestellt) und flashe sie mit esptool: 

python -m pip install esptool
esptool.py --port COM3 --baud 460800 write_flash 0x0 aiuto-vista-v0.6.0.bin

Bei Linux lautet der Port meist /dev/ttyUSB0, bei macOS /dev/tty.usbserial-…. Alternativ eignet sich auch die Arduino-IDE mit installiertem ESP32-Kern, um die .bin-Datei zu flashen.
