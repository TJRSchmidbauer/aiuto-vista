ScopeBuddy installieren

Übertrage ScopeBuddy 0.5 direkt aus dem Browser auf dein Elecrow CrowPanel Advanced 5″ mit ESP32-P4.

Stabile Version 0.5

Bereit zur Installation

  1. CrowPanel mit einem USB-Datenkabel an den Computer anschließen.
  2. Auf „Mit Gerät verbinden“ klicken und den seriellen Anschluss auswählen.
  3. Die Installation bestätigen und das Kabel nicht abziehen.

Dieser Browser unterstützt die Installation nicht. Bitte verwende Chrome oder Edge auf einem Desktop-Computer.

Der Browser hat den Zugriff auf die serielle Schnittstelle blockiert.

Achtung: Nur für das Elecrow CrowPanel Advanced 5″ mit ESP32-P4. Die Browser-Installation setzt gespeicherte ScopeBuddy-Einstellungen zurück. „Gerät löschen“ entfernt zusätzlich alle übrigen Flash-Daten.

Wenn keine Verbindung zustande kommt

Schließe andere Programme mit serieller Verbindung, probiere ein anderes USB-Datenkabel und lade diese Seite neu. Falls das Board nicht automatisch in den Download-Modus wechselt, halte die BOOT-Taste gedrückt, betätige kurz RESET und lasse anschließend BOOT los.
